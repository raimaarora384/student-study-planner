# 📚 Student Study Planner

An automated student study planner built using **n8n** that helps students create a personalized study schedule and automatically sends it to their email.

## 🎯 Problem

Students often know what subjects they need to study but struggle to organize their available time effectively.

This project automates the process of creating and delivering a study schedule based on the student's inputs.

## ⚙️ How It Works

The workflow follows these steps:

1. The student fills out a form with their study requirements.
2. The information is received by the n8n workflow.
3. The workflow processes the submitted information.
4. A personalized study schedule is generated.
5. The completed schedule is automatically sent to the student's email.

## 🔄 Workflow

**Student Form → n8n → Schedule Generation → Email**

## 🛠️ Technologies Used

- n8n
- Form / Form Trigger
- Email automation
- JSON workflow

## ✨ Features

- Automated study schedule generation
- Personalized planning based on student inputs
- Automatic email delivery
- Reduces the need for manually creating study timetables
